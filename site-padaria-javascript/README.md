# Site Pão & Afeto — JavaScript puro

## Abrir
Extraia o ZIP e abra `index.html` no navegador. Para editar, abra a pasta no VS Code.

## Funcionalidades
- Site responsivo para celular e computador.
- Catálogo com categorias e pesquisa.
- Carrinho com quantidade e total automático.
- Carrinho salvo no navegador via localStorage.
- Formulário de pedido que gera resumo em TXT.
- Integração opcional com WhatsApp.

## Personalizar
- `script.js`: edite `products` para alterar produtos, preços, descrições e fotos.
- `script.js`: preencha `STORE.whatsapp` com DDI + DDD + número, apenas dígitos (ex.: `5511999999999`).
- `index.html`: altere nome, endereço, telefone e horários da padaria.

## Observação
Esta é uma versão front-end. Os pedidos ficam no navegador/arquivo do cliente. Para receber e administrar pedidos centralizados, cadastrar produtos por painel administrativo, controlar estoque e pagamentos, é necessário backend e banco de dados.
